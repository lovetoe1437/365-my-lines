# 365 МОИХ СТРОК

**Название проекта:** 365 моих строк
**Тип проекта:** Премиальная цифровая книга
**Технологии:** Astro
**Текущее состояние:** Выпущенная версия 1.3.0

---

# О ПРОЕКТЕ

Этот проект — не блог, не сайт заметок и не обычный дневник.

Это цифровое продолжение настоящей печатной книги.

Внутри бумажной книги находится QR-код. После его сканирования человек попадает на этот сайт.

Главная цель проекта — создать ощущение, что пользователь продолжает читать настоящую книгу, а не открывает веб-сайт.

Каждое решение в проекте должно усиливать именно это ощущение.

---

# ОСНОВНАЯ КОНЦЕПЦИЯ

Проект состоит из двух больших разделов.

## Книга

Опубликованные страницы.

Это законченные мысли, которые читает человек.

Во время чтения пользователь должен забывать, что находится в браузере.

Максимально спокойный интерфейс.

Минимум элементов управления.

Отличная типографика.

Комфортная ширина строки.

Большие поля.

Аккуратные отступы.

Плавные анимации.

Никаких отвлекающих элементов.

---

## Дневник

Место, где появляются новые записи.

Он существует отдельно от книги.

Это не админ-панель.

Не CMS.

Не редактор блога.

Он должен выглядеть как место, куда автор спокойно записывает новые мысли.

# ПРИНЦИПЫ РАЗРАБОТКИ

Перед внесением изменений необходимо:

1. Изучить существующую архитектуру.
2. Проверить, нет ли уже готового решения.
3. Не создавать дублирование компонентов.
4. Не создавать дублирование CSS.
5. Использовать существующую систему проекта.
6. Не ломать мобильную версию.
7. Не ухудшать производительность.

---

# ЧТО НЕЛЬЗЯ ДЕЛАТЬ

* не менять стиль проекта без причины;
* не добавлять новые библиотеки без необходимости;
