# Постоянные QR-коды

Файлы предназначены для печатного издания «365 моих строк».

## Адреса

- `prologue-qr.svg` и `prologue-qr.png` → `https://365mylines.com/prologue`
- `main-qr.svg` и `main-qr.png` → `https://365mylines.com/`

## Использование

- Для печати предпочтителен формат SVG.
- PNG подготовлен в размере 2048 × 2048 пикселей.
- Вокруг кода сохранено стандартное свободное поле в четыре модуля.
- Цвет кода — чёрный, фон — белый.
- Коррекция ошибок — уровень H.
- Не обрезать свободное поле и не растягивать изображение непропорционально.
- Перед тиражной печатью проверить пробный экземпляр на нескольких телефонах.

QR-коды статические и не зависят от стороннего сервиса. Они будут работать, пока доступны указанные адреса.
