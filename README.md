# 365 моих строк

Личная цифровая книга, продолжающая печатное издание. Проект доступен по адресу [365mylines.com](https://365mylines.com) и задуман как спокойное, приватное пространство для чтения и новых записей.

## Что есть в проекте

- читательский вход по общему паролю;
- отдельный авторский вход для создания и редактирования;
- книга и личный дневник;
- до шести фотографий в каждой записи; изображения преобразуются в WebP и хранятся в закрытом Cloudflare R2;
- публичный пролог по адресу `/prologue` для QR-кода из печатной книги;
- приватная статистика посещений в `/admin/visits` с фильтрами «человек», «вероятный бот» и «не определено»;
- карточка предпросмотра для ссылок в мессенджерах;
- ежедневная резервная копия D1 в закрытый артефакт GitHub Actions.

## Доступ

| Адрес | Назначение | Доступ |
| --- | --- | --- |
| `/` | Страница читательского входа | Пароль читателя |
| `/prologue` | Письмо перед чтением печатной книги | Открыт по прямой ссылке |
| `/lines` и `/pages/:id` | Чтение книги и дневника | Сессия читателя |
| `/login` | Авторский вход | Пароль автора |
| `/write`, редакторы и `/admin/visits` | Создание, редактирование и статистика | Авторская сессия |

Основной QR-код ведёт на `/`, а QR-код пролога — на `/prologue`. QR-коды статичны и не требуют обновления после изменений дизайна сайта.

## Технологии

- Astro 7 в серверном режиме;
- Cloudflare Workers;
- Cloudflare D1 для записей и статистики;
- Cloudflare R2 для фотографий;
- Cloudflare KV для сессий и ограничения попыток входа;
- TypeScript и CSS без клиентского фреймворка.

Требуется Node.js `22.12.0` или новее.

## Локальный запуск

```bash
npm install
npx wrangler d1 migrations apply 365-my-lines-db --local
npm run dev
```

Сайт будет доступен по адресу `http://localhost:4321`.

Для локальной работы создайте `.dev.vars` и задайте тестовые значения. Не добавляйте этот файл в Git:

```dotenv
READER_PASSWORD=локальный-пароль-читателя
ADMIN_PASSWORD=локальный-пароль-автора
VISITOR_HASH_SECRET=длинное-случайное-тестовое-значение-не-меньше-32-символов
```

## Проверки

```bash
npm test
npm run build
```

GitHub Actions запускает на каждом push в `main` проверку зависимостей, аудит production-зависимостей, тесты и production-сборку.

## Резервные копии

Локальная резервная копия D1:

```bash
npm run backup:d1
```

Команда создаёт SQL-файл в игнорируемой Git папке `backups`. В production ежедневный снимок сохраняет базу и копию фотографий в закрытый R2-бакет `365-my-lines-backups`; его краткая копия также хранится как закрытый артефакт GitHub 30 дней. Для этого в секретах репозитория нужны `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_R2_BACKUP_TOKEN`; значения токенов не хранятся в коде.

Фотографии в R2 не являются публичным бакетом: они выдаются только через защищённый маршрут сайта. Удаление фотографии или записи удаляет связанный объект из R2.

## Безопасность и приватность

- все страницы, кроме `/access`, `/prologue` и технических публичных файлов, требуют читательской сессии;
- редакторы, API изменения данных и админка требуют авторской сессии;
- формы принимаются только с доверенных источников сайта;
- приватные ответы не кэшируются браузером;
- поисковикам запрещён обход сайта через `robots.txt`, sitemap пустой;
- полный IP-адрес в статистике не сохраняется: используется HMAC для дедупликации;
- время на сайте учитывается только в читательских разделах, а не в редакторах и админке.

## Структура

- `src/pages` — страницы и API-маршруты;
- `src/components` — компоненты чтения, редакторов и интерфейса;
- `src/lib/auth` — сессии, пароли и ограничение попыток входа;
- `src/lib/db` — доступ к D1;
- `src/lib/images` — проверка, обработка и хранение фотографий;
- `src/lib/visits` — приватная статистика посещений;
- `migrations` — миграции D1;
- `tests` — автоматические тесты;
- `assets/qr` — постоянные QR-коды;
- `docs` — техническая и эксплуатационная документация.
