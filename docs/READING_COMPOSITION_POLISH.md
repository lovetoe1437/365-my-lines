# Reading Composition Polish

This update fine-tunes the reading page without changing its structure or behavior.

## Changes

- Reduced the visual weight of the top toolbar.
- Tightened the distance between page number and title.
- Slightly reduced the maximum title size for long headings.
- Added more breathing room between title and date.
- Moved the prose closer to the heading ornament.
- Narrowed the main text column and softened paragraph rhythm.
- Reworded the desktop page counter as “Страница N из 365”.
- Kept the compact `N / 365` counter on mobile.
- Preserved reduced-motion behavior and page-turn navigation.

## Review checklist

Check at least:

1. A very short entry.
2. A long entry with six or more paragraphs.
3. A long title.
4. Desktop width around 1440–1600 px.
5. Mobile widths around 390–430 px.
