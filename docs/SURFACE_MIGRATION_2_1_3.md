# Surface Migration 2.1.3 — Pilot

Дата: 23 июля 2026

## Область изменения

Пилот выполнен только на странице `src/pages/404.astro`. Это намеренно маленькая область изменения для проверки совместимости Foundation-компонентов с Astro scoped CSS.

## Что внедрено

- `Paper` заменил нативный корневой `article` карточки.
- `Eyebrow`, `Heading` и `Text` подключены для редакционной типографики.
- Сохранены исходные семантические HTML-теги.
- Существующие визуальные классы сохранены как контракт страницы.
- Селекторы корневых элементов дочерних Astro-компонентов переведены на `:global(...)`, чтобы scoped CSS продолжал достигать отрендеренного HTML.

## Что намеренно не менялось

- цвета;
- размеры;
- отступы;
- тени;
- адаптивность;
- кнопки;
- анимации;
- остальные страницы.

## Проверка владельцем проекта

1. Запустить `npm run dev`.
2. Открыть несуществующий адрес, например `/lines/33`.
3. Сравнить desktop и mobile с baseline.
4. Проверить панель Problems в VS Code.
5. После подтверждения использовать тот же подход для следующей простой поверхности.

## Критерий успеха

Пилот считается завершённым, если внешний вид страницы совпадает с baseline и не возникает новых ошибок сборки или scoped CSS.
