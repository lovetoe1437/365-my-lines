# TASK-A3 — Unified Delete Dialog

## Статус

Завершено после визуального hotfix.

## Что сделано

- Создан единый компонент `src/components/DeleteConfirmDialog.astro`.
- Один и тот же фирменный диалог используется в книге и дневнике.
- Удалён упрощённый вариант окна редактора.
- Сохранены прежние идентификаторы элементов и существующая логика API удаления.
- Сохранены закрытие по кнопке отмены, крестику и клику по фону там, где оно уже обрабатывалось страницей.
- Мобильная версия использует вертикальное расположение кнопок.

## Проверка

1. Открыть редактирование страницы книги.
2. Нажать «Удалить страницу».
3. Убедиться, что показано фирменное окно с рамкой, орнаментом и красной кнопкой.
4. Повторить проверку в редакторе дневника и на странице чтения дневника.
5. Проверить отмену, крестик и фактическое удаление.
