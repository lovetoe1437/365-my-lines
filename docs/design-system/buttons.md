# Buttons

Компонент: `src/components/ui/Button.astro`.

## Варианты

- `primary` — главное действие экрана.
- `secondary` — альтернативное действие.
- `ghost` — спокойное служебное действие.
- `danger` — подтверждённое разрушительное действие.
- `link` — действие, визуально встроенное в текст.

## Размеры

`sm`, `md`, `lg`. Размер по умолчанию — `md`.

## Состояния

Компонент поддерживает `disabled`, `loading`, `fullWidth` и `iconOnly`. Для icon-only обязательно передавать `label`.

На одном небольшом экране обычно должно быть не больше одного `primary`-действия.
