# Design System — 365 моих строк

Эта папка фиксирует визуальный фундамент проекта. Любой новый интерфейс сначала использует существующие токены и компоненты. Новый токен или вариант компонента добавляется только тогда, когда существующая система действительно не решает задачу.

## Принципы

1. Сначала система, потом исключения.
2. Семантические токены важнее конкретных цветов и размеров.
3. Одинаковое назначение всегда получает одинаковое визуальное поведение.
4. Мобильная версия является основной точкой входа.
5. Доступность и `prefers-reduced-motion` не считаются дополнительными улучшениями — это часть базового качества.
