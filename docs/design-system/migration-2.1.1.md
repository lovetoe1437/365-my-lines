# Foundation Migration 2.1.1

## Цель

Начать безопасный перевод существующих страниц на Foundation System без изменения утверждённого визуального дизайна.

## Выполнено

- `Section` теперь поддерживает семантический элемент `main`.
- Корневой контейнер `AppLayout` изменён с `main` на нейтральный `div`, чтобы исключить вложенные или повторяющиеся основные landmarks.
- Главная страница, оглавление книги, страница чтения, вход, 404 и редактор Unspoken переведены на `Section`.
- Сохранены исходные CSS-классы, поэтому композиция, размеры, анимации и адаптивность не изменились.

## Принцип миграции

Миграция выполняется поэтапно: сначала семантические layout-примитивы, затем поверхности и типографика. Визуально чувствительные элементы не переводятся автоматически, пока их соответствие утверждённому дизайну не проверено отдельно.
