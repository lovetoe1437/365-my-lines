# Accessibility

- Все интерактивные элементы имеют видимый `:focus-visible`.
- Icon-only кнопки получают доступное имя через `label`.
- Disabled-ссылка удаляет `href`, получает `aria-disabled` и исключается из tab-порядка.
- Loading-состояние использует `aria-busy` и блокирует повторное действие.
- Минимальная стандартная высота интерактивного элемента — 48 px; компактный размер применяется только в служебных областях.
