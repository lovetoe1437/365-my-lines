# Reading Experience 1.9

This iteration focuses on reading comfort rather than visual redesign.

## Principles

- The text column is measured in characters, not only pixels.
- Short, regular, and long entries retain distinct pacing.
- Paragraph spacing and line height form a predictable vertical rhythm.
- Mobile navigation stays available without visually competing with the text.
- Swipe navigation never overrides intentional interaction with links and controls.
