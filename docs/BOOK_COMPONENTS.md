# Book Components

Первая внутренняя библиотека компонентов проекта «365 моих строк».

## Принцип

Компонент появляется не ради абстракции, а когда один и тот же смысл или фрагмент интерфейса повторяется в нескольких местах.

> Если один и тот же фрагмент появился три раза, он становится компонентом.

## `src/components/book/BookOrnament.astro`

Фирменный разделитель книги: две линии и центральный символ. По умолчанию декоративный и скрыт от скринридеров.

Параметры:

- `class` — класс конкретного экрана;
- `symbol` — центральный знак, по умолчанию `✦`;
- `label` — доступное описание, только если орнамент несёт смысл.

## `src/components/editor/EditorMeta.astro`

Единая строка состояния редактора:

- статус автосохранения;
- счётчик символов;
- стабильные `id`, которые использует `createEditor.ts`.

Компонент поддерживает разную разметку книги и дневника без дублирования логики.

## `src/components/editor/EditorActions.astro`

Единая пара действий редактора:

- отмена;
- сохранение.

Тексты и адрес возврата передаются параметрами, поэтому книга и дневник сохраняют собственный язык.

## Граница рефакторинга

На этом этапе компоненты внедрены только там, где повторение уже очевидно. Крупные страницы не дробятся преждевременно: `Paper`, `ReadingFooter` и другие элементы будут вынесены только после появления устойчивого повторения.
