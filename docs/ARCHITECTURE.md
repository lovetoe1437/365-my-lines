# Архитектура

Проект построен на Astro и разворачивается через Cloudflare. Динамические записи хранятся в D1, а серверные маршруты работают через Astro API endpoints.

## Основные каталоги

- `src/pages` — страницы и API-маршруты.
- `src/layouts` — общая HTML-обвязка страниц.
- `src/components` — повторно используемые интерфейсные компоненты.
- `src/lib/db` — работа с D1.
- `src/lib/auth` — авторизация и сессия.
- `src/lib/ui` — чистые UI-утилиты без доступа к базе данных.
- `src/styles` — дизайн-токены и глобальные стили.

## Правила

1. Не дублировать форматирование дат и определение состояния навигации в страницах.
2. Повторяющиеся цвета, тени и размеры выносить в `variables.css`.
3. Серверную работу с данными держать в `src/lib/db`, а не внутри компонентов.
4. Не добавлять библиотеку, если задачу ясно решают Astro, TypeScript и CSS.
